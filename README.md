# VibeBook-Rede Social
Perfil Personalizável: Um espaço individual onde cada usuário pode expressar sua "vibe", exibindo biografias e galerias de fotos.  Sistema de Interações: Ferramentas fluidas de engajamento, incluindo reações e comentários.  Mensagens e Conexões: Sistema de amizades e chat integrado para conversas privadas ou em grupo.
